# Hasil Modul: Modern Web: Toko Online (ThriftKita)

Ini web yang dihasilkan kalau siswa mengikuti 6 modul course **Modern Web: Toko Online**.

- `index.html`: HTML hasil Modul 1 (kerangka, kartu produk, link WhatsApp).
- `style.css`: **dirakit otomatis dari blok kode ` ```css ` di Modul 2 sampai 5**, sesuai urutan kemunculan. File ini membuktikan bahwa modul memuat semua kode yang dibutuhkan. Hasil render-nya identik piksel demi piksel dengan solusi acuan di `seminar-sifest/level-up/thriftkita/`.
- `img/`: foto produk dari [Unsplash](https://unsplash.com) (lisensi bebas pakai).

Cara melihat: klik kanan `index.html` di VS Code, lalu Open with Live Server (atau buka langsung di browser).

Catatan: nomor WhatsApp `628123456789` hanya contoh. Ganti dengan nomormu sendiri untuk mencoba tombol beli.

Uji dark mode: aktifkan mode gelap di pengaturan sistem, atau di DevTools tekan `Ctrl + Shift + P`, ketik `dark`, lalu pilih Emulate CSS prefers-color-scheme: dark.
