- Clean
- Premium

# LAYOUT SYSTEM

Prefer:

60/40 layouts

Examples:

Left:
Content

Right:
Illustration

or

Left:
Diagram

Right:
Explanation

---

Use large whitespace.

Never fill every corner.

Slides should feel breathable.

---

# CARD SYSTEM

Cards should have:

- rounded corners
- subtle shadows
- minimal borders

Card Background:

#FFFFFF

Border:

#DDD7CF

Radius:

16px+

---

# ICON STYLE

Preferred:

- Outline Icons
- Minimal Icons
- Monoline Icons

Avoid:

- Cartoon icons
- Emoji style icons

---

# DIAGRAM STYLE

Use:

- Process Flow
- Flowchart
- Timeline
- Comparison Cards

Avoid:

- Complex UML
- Dense technical diagrams

---

# ILLUSTRATION STYLE

Preferred:

Modern SaaS Style

Examples:

- laptop mockups
- coding screens
- workflow illustrations
- AI agent illustrations
- abstract 3D shapes

---

Illustrations should use:

- beige
- soft purple
- neutral gray

to match brand colors.
