# PRODUCT REQUIREMENT DOCUMENT

## Product Name

Padel Court Booking System

---

## Product Overview

Aplikasi untuk membantu proses booking
lapangan padel secara digital.

---

## Problem Statement

Saat ini proses booking dilakukan
melalui WhatsApp sehingga:

- Bentrok jadwal
- Sulit tracking booking
- Tidak ada histori
- Tidak ada dashboard admin

---

## Goals

- Mempermudah booking
- Mengurangi human error
- Menyediakan kalender booking
- Menyediakan dashboard admin

---

## Users

### Customer

Melakukan booking lapangan

### Admin

Mengelola jadwal dan booking

---

## Features

### Authentication

- Login
- Register

### Booking

- Buat booking
- Cancel booking

### Calendar

- Lihat jadwal

### Dashboard

- Kelola booking

---

## Success Metrics

- Booking berhasil dibuat
- Jadwal tidak bentrok
- Admin dapat mengelola booking
